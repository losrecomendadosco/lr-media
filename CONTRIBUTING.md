# Contributing media

Thanks for keeping the LR media library organized.

## Upload checklist

Before committing an asset:

- [ ] I have permission to use and distribute this asset.
- [ ] The asset does not contain secrets, credentials, or private personal information.
- [ ] The asset is in the correct top-level folder and category.
- [ ] The filename is lowercase, descriptive, and uses hyphens instead of spaces.
- [ ] The file is compressed and below 100 MB.
- [ ] I checked that I am not creating a duplicate of an existing asset.
- [ ] The commit message explains what was added and why.

## Direct upload vs pull request

Routine, approved media can be uploaded directly to `main` by organization members. Use a branch and pull request when:

- the asset is public-facing and requires content or brand review;
- several files are being added or reorganized;
- an existing asset is being replaced or removed; or
- you are unsure whether the asset is approved.

## Removing or replacing files

Do not remove an asset only because a newer version exists. Check repository usage first. Prefer adding a versioned file, then update consuming projects separately. If an asset must be removed, explain the reason in a pull request.

# Contributing media / Contribuir con medios

Thanks for keeping the LR media library organized. / Gracias por mantener organizada la biblioteca de medios de LR.

## Upload checklist / Lista de comprobación

Before committing an asset: / Antes de hacer commit de un recurso:

- [ ] I have permission to use and distribute this asset. / Tengo permiso para usar y distribuir este recurso.
- [ ] The asset does not contain secrets, credentials, or private personal information. / El recurso no contiene secretos, credenciales ni información personal privada.
- [ ] The asset is in the correct top-level folder and category. / El recurso está en la carpeta principal y categoría correctas.
- [ ] The filename is lowercase, descriptive, and uses hyphens instead of spaces. / El nombre está en minúsculas, es descriptivo y usa guiones en vez de espacios.
- [ ] The file is compressed and below 100 MB. / El archivo está comprimido y pesa menos de 100 MB.
- [ ] I checked that I am not creating a duplicate of an existing asset. / Confirmé que no estoy creando un duplicado.
- [ ] The commit message explains what was added and why. / El mensaje de commit explica qué se agregó y por qué.

## Direct upload vs pull request / Carga directa vs solicitud de cambios

Routine, approved media can be uploaded directly to `main` by organization members. / Los miembros de la organización pueden subir directamente a `main` los medios rutinarios y aprobados.

Use a branch and pull request when: / Usa una rama y una solicitud de cambios cuando:

- the asset is public-facing and requires content or brand review; / el recurso es público y necesita revisión de contenido o marca;
- several files are being added or reorganized; / se agregan u organizan varios archivos;
- an existing asset is being replaced or removed; or / se reemplaza o elimina un recurso existente; o
- you are unsure whether the asset is approved. / no estás seguro de que el recurso esté aprobado.

## Removing or replacing files / Eliminar o reemplazar archivos

Do not remove an asset only because a newer version exists. Check repository usage first. / No elimines un recurso solo porque existe una versión más nueva. Primero revisa su uso en el repositorio.

Prefer adding a versioned file, then update consuming projects separately. / Prefiere agregar un archivo con versión y actualizar después los proyectos que lo usan.

If an asset must be removed, explain the reason in a pull request. / Si es necesario eliminar un recurso, explica el motivo en una solicitud de cambios.
